Total: 144 callout silhouettes on 25 figures. Each figure's JSON `notes` lists
the exact references without a proposed silhouette. These are approximate manual
contours of the leader-indicated physical components, not numeral outlines or
generic marker boxes. A mask may include the connected assembly envelope when
the printed reference identifies the assembly. Separate similar hardware is
not assigned merely from appearance or quantity. Evidence is attached to every
annotation in `part-highlights.json`.

Whole-image percentage geometry is bound to current drawing paths, SHA-256
hashes and dimensions, plus the current catalogue SHA-256 and exact imported
callout / figure-part / part-number identity. Validation confirmed all hashes,
identities and finite polygon coordinates inside 0–100. Actual browser overlay
alignment and interaction verification belongs to the integrating viewer task.
These data do not establish that all 45 figures support physical-part fills.

Cabin 6.13 remains completely excluded because of its existing source-label
conflicts. Cabin 6.17 reference 16 is also withheld from silhouette assignment:
its visible tray-like object needs reconciliation with the imported description
"Minibus air conditionner". No source identity is inferred from appearance.
